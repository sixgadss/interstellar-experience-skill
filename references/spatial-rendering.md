# 空间渲染与视觉判断

## 真正的深度

用稳定的三维位置描述星点、星尘、星系锚点和可点击标记。旋转与平移使用同一镜头，避免背景一套视角、星点另一套视角。贴图可表达远处银河细节，近景星尘仍需要世界坐标；移动一张背景图不能替代三维场景。

旋转用归一化四元数保留三个轴；选择最短旋转弧。保留 focus、orientation、zoom 的完整状态。近处物体移动更快是投影产生的真实深度线索，不额外叠加装饰性的鼠标视差。

对于使用虚拟镜头距离 `d / zoom` 的投影，深度缩小时直接除以 zoom 可能溢出。将分子分母同乘 zoom，在裁剪平面上判断 behind，再计算屏幕位置。极小 zoom 应产生有限值；屏幕半径与点击尺寸仍需单独约束。其他镜头模型沿用其自身单位和投影约定。

## 星点与星云

- 用确定性随机种子生成分布，避免刷新和 resize 重新洗牌。
- 均匀球面：经度均匀、`cos(latitude)` 均匀；不是纬度直接均匀。
- 银河可采用倾斜盘、旋臂、中心密集与外缘稀疏的分布，保留少量离盘星。形状调整改变真实位置，而不是只换轮廓图片。
- 内容星与环境星分离：前者可访问和编辑，后者表达空间。相关内容形成附近星群，淡线表达经阈值筛选的相似关系；私密记录的名称、摘要、文件或连线不能漏进公开快照。
- 星云使用低对比的体积、吸收或密度变化。颜色来源于用户选择和设计 token，避免随意增加彩色光晕。遵守项目的色相、强调面积和渐变限制。
- 不用虚构的光年、排名、访客数量或科学精度给界面增添可信感。

## 清晰度与性能

Canvas 的 CSS 尺寸和像素缓冲尺寸分开；按设备 DPR 提升清晰度，并设置与设备能力匹配的像素预算。字体保留在 DOM，避免画到低分辨率缓冲里。低端设备优先减少体积采样、环境点数或特效分辨率，保留内容标记和点击准确性。

缓存随机分布、纹理、布局和颜色解析。避免每帧读样式、创建渐变、生成星点或重建 DOM。动态时只更新必要的 transform/opacity；静止后不继续消耗无意义的 RAF。控制标签长度和可点击目标尺寸，避免近景星点膨胀成大白圆。

没有 WebGL 时可以回退到同样镜头模型的 Canvas 星点；明确报告体积星云未验证或不可用。不要用模糊的平面图假称完整三维能力。
