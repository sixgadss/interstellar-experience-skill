# 内容、发现与验收

## 生活积累与个人展示

真实记录作为内容星；空白星用于创建。可选的入口星帮助访客快速认识主人，最近记录提供按真实时间回看的路径，快速记录把捕捉想法缩短到一个主要动作。数量和布局根据已有内容决定，不伪造生活经历或活跃度。

阅读使用足够宽的文字列与明确返回操作，不把正文绕进三维球面。进入后停稳；返回恢复出发视角。保留即时焦点环、可读对比度、触屏目标和 keyboard 路径。手势失败时仍能完成阅读与记录。

首次打开已有记录时缺失日期就显示未知或不显示；不能批量填今天。自动保存文字草稿与已保存内容区分开，绑定真实 record ID，防止编辑记录后把草稿仍留在快速入口键下。附件通常在明确保存后提交；撤销、文件错误和恢复不要偷偷改变其他记录。

## 兴趣相遇

相似度来源于可观察的标签、内容词、用户选择或明确的模型输出。相近星点在空间上聚集，联系线保持稀疏；相似度不是物理引力模拟的科学证据。访客先发现星系和一份可读内容，再主动靠近。附近示例必须标为示例，不暗示真实用户在线。

共享快照只包含明确选中的公开记录及允许公开的附件。重写相关连线/引用，排除私密名称和悬空 ID。留言与收藏明确保存范围；没有认证/后端时不要声称跨设备同步或真实主人能收到通知。备份/恢复覆盖私密记录和附件时，由用户决定是否导出；发布 Skill 或模板时排除这些数据和云端凭据。

## 最小验收矩阵

| 条件 | 观察到的结果 |
| --- | --- |
| 非默认朝向、平移与缩放出发 | 读完返回，场景 ID 和完整镜头快照一致 |
| 背景暂停 | 进入仍有有限航行，抵达后不继续自动漂移 |
| 航行中选择 B 或打开分享/设置 | A 被取消；旧阅读器和附件不迟到弹出 |
| 拖动、缩放、手势接管返航 | 镜头从当前位置响应输入，不被旧航程拉回 |
| 减少动态效果 | 直接抵达与返回，仍能用键盘完成动作 |
| 切走标签页再回来 | 保持航程进度，镜头不补跳隐藏时长 |
| 标记靠近返回/筛选/缩放按钮 | 只读 hit-test 和真实点击均落到控件 |
| 320 / 375 / 414 / 768 / 1440px | 无横向溢出，主要控件可见、单行且可点击 |
| 极小 zoom、无 WebGL、低端设备 | 数值有限、有可用回退，内容与点击保持清晰 |
| 公开分享或导出离线 HTML | 私密内容不进入包，文件和引用没有悬空 |

测试镜头示例：`node --test assets/flight.test.cjs`。覆盖连续抵达、精确返回、替换/取消、减少动态效果、极小 zoom、最短旋转弧与帧率一致性。它们不能替代实际浏览器的点击、布局或摄像头手势验收。

对 web 和离线版本核对脚本内容、顺序、纹理、模型与 WASM；不要只比文件名或版本号。支持的服务是否在线与 HTML 能否离线浏览分别验证。公网部署成功需要服务返回终态并打开实际页面核实；保存一个版本不等于上线。记录实际测试证据和未测试设备，不把理论支持写成已验证功能。
